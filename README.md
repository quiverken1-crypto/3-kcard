# 三国KARDS

## 启动

Windows 上双击 `一键启动游戏.cmd` 即可，不需要 Node.js；保持启动窗口打开，游戏会在默认浏览器出现。如果 8088 端口已被占用，启动器会自动尝试 8089–8100。也可以安装 Node.js 后进入本文件夹运行 `node server.js`，打开 `http://localhost:8088`。联机时双方各自启动游戏，并通过游戏内“联机设置”交换连接码。

## 操作

- 点击手牌，再点击己方支援阵线打出；拥有“奇袭”的单位也可直接点选前线。也可以把手牌拖到目标区域。
- 非指向性战法点选后，可在战场任意区域释放；选中的手牌会轻微抬起，鼠标右键可取消选中。
- 点击己方单位，再点击发亮的区域移动，或点击标出的敌方目标攻击。
- 计时：每步思考 40 秒（每次行动后重置），每回合总计 80 秒；总时间剩 30 秒时特别提示。调度阶段超时自动保留手牌进入行动阶段，行动阶段超时自动结束回合。联机时由房主执行超时判定。
- 点击卡牌上的“详”查看完整技能与词条说明；右键点击也可以打开详情。
- 小窗口中，战场、手牌和状态栏可分别滚动；“结束回合”始终显示在右下角。
- 背景音乐与行动音效默认开启；可在战报抽屉里调节音量或静音。
- 连接页可分别选择本地的连接页和对局音乐文件；这些文件只在当前浏览器会话使用，不会进入分享包。

## 音频授权

默认连接页与对局音乐分别取自用户指定的《长安》和《三国杀主题曲》视频音轨；刀剑、脚步等音效及两首备选音乐来自开放素材。逐文件来源和已知授权状态见 [音频清单](assets/audio/LICENSES.md)。这两首原曲并非开源素材，请勿将含原曲的压缩包公开发布。

## 更新：攻击判定 / 掉帧 / 竖屏
- 攻击判定：手指轻微抖动（选中己方单位时滑动超过 6px）会被当成“拖动”而悄悄取消选中，导致再点目标没反应——触屏阈值放宽到 14px，拖回自身保持选中；目标卡牌边缘/缝隙 22px 内也算点中。
- 点到打不了的敌军或主城时会提示原因（守护、射程不相邻、步兵移动后、刚部署、鲁肃·结盟、帷幄等），选中状态保留可换目标；选中单位时如果完全没有目标也会提示。
- 重绘战场后自动补回选中高亮（之前重绘会让高亮丢失、点击失效）。
- 「✕ 取消」按钮移到左下角，不再盖住敌方支援阵线。
- AI 修复：模拟推演用的状态拷贝是浅拷贝，推演会改到真实对局（回合增益等），导致 AI 做出非法攻击后整个回合卡死；改为深拷贝，另外 AI 行动被拒时自动结束回合。
- 掉帧：手机上关闭 box-shadow 呼吸光、水面流动等每帧重绘的无限动画（改静态发光）。空闲时 GPU 栅格化从约 20% 降到接近 0，减少发热降频导致的“突然卡一下”。
- 竖屏：倒计时只显示秒数并收窄，不再挡住声望。

## 更新：自定义工坊 v2
- **卡牌**：名称、势力、类型（单位/战法/反制）、兵种（含器械）、部署/行动费用、战力/生命、张数上限（1–3）；词条（内置词条一键添加）、性格、自定义词条（带释义，会出现在词条说明里）、技能名与描述。
- **技能实现二选一**：“积木效果”（时机 → 效果 → 目标 → 数值，保存即在对局生效）；或“文字描述，交给开发者实现”（卡牌标“待实现”，对局中卡面注明“技能待实现”，暂无效果）。
- **势力**：新建势力（简称、军名、颜色、1–2 座主城及各 2 张地形）。新势力需要先做够卡、在「卡组」里组成合法卡组才能开局；也可作为双阵营的副阵营。人机对手只使用内置势力。
- **导入 · 导出**：勾选多项（可“只选待实现”）→ 下载 `三国KARDS-自定义-日期.json` 或生成卡包码（`SGKP1-…`，不含图片）。导入支持文件或卡包码；同标识内容不同时可选另存副本 / 覆盖 / 跳过。
- **并入官方卡牌库**：把导出的文件发给开发者，由开发者实现“待实现”的技能后合入 `cardDB.js`。
- **卡组分享码**会自动带上卡组里用到的自定义卡和势力，对方导入时一并加入其工坊；联机时对方的自定义卡只在本局内存中使用，不写入本机工坊。
- 数据保存在本机浏览器（localStorage `sgk_custom_v2`，旧版 `sgk_custom_cards_v1` 自动迁移）。
